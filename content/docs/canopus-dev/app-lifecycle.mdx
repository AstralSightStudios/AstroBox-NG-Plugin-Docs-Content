先说一个容易混淆的点：退出 App 的页面，不等于把模块停用了。Canopus 模块还在，只是页面的控件和刷新回调会被清理掉。如果你有退出页面后还要继续跑的定时器，它应该归模块管，不能挂在页面对象上，否则页面一销毁，回调就可能去碰已经释放的内存。

## 注册应用

模块加载时，`prepare` 负责检查服务、初始化状态，`activate` 再启动真正的功能。控件不要在这一步就建，等用户打开页面时再创建，省得模块在后台挂着一堆用不到的 UI 对象。入口的签名和返回值见[模块回调](/docs/canopus-dev/sdk#注册模块)。

如果只需要管理器详情页里的「打开界面」，调用 `ctx->ui->set_entry` 就够了。要让模块出现在手环的应用列表里，则是另一回事：得从模块所属的 UI 任务调用 `ctx->launcher->register_app`。这里有一个顺序要求，登记托管页面之前必须先调用 `set_entry`；原生页面还要传与固件匹配的描述符，通常是在原生应用的发布回调里登记。`register_app` 返回一个供导航使用的应用 ID，但这还没完，固件还要在后续的 UI 回调中完成注册。

[Launcher 服务](https://github.com/AstralSightStudios/Canopus/blob/main/docs/canopus-services-specification.md#213-ctx-launcher--模块自己的启动器入口)没有同步注销接口。原生应用模块用 `resident-after-activation` 保持驻留，描述符和固件引用的回调要到重启才可以失效。换句话说，注册这件事在本次开机内基本是单向的，别指望运行时说撤就撤。

## 打开、离开和返回页面

从子页返回时，原来的页面可能还在，固件会调 `on_resume`，不一定再调 `on_create`。所以 `on_resume` 里不能假设控件是刚建好的，也不能无脑再建一套刷新定时器。原生页面的这些回调都在 UI 所属任务执行。

| 回调 | 页面要做的事 |
| --- | --- |
| `on_create` | 在固件传入的根容器里建控件。建到一半失败，清理已经分配的资源。 |
| `on_resume` | 用当前数据更新页面。刷新定时器已经在跑就别再建一个。 |
| `on_pause` | 停止页面刷新，取消或收尾正在播放的动画。留下恢复时要用的页面状态。 |
| `on_ui_destroy` | 先取消还会访问页面的回调，再释放页面资源、清掉控件引用。 |

返回逻辑要按层级来：有弹层就先收起弹层，有子页就退回上一页，到了根页再交给系统。标题栏按钮和系统手势可能走不同的回调，两个入口都得试，别只测一种。如果退场动画播完才关页，页面被提前销毁时记得取消那个结束回调，否则它还可能去关下一页。

[托管页面](https://github.com/AstralSightStudios/Canopus/blob/main/docs/canopus-services-specification.md#212-ctx-ui--语义-ui-树事件与模块页面)用的是另一组回调。`on_open` 返回前要提交 UI 树，`on_close` 返回后页面句柄就不能再用了。还有一个坑：模块卸载时不会补调 `on_close`，所以还握在模块手里的资源，要在停止时自己清掉。

## 息屏后还要继续的任务

息屏后，普通 UI 定时器可能不再触发。倒计时不能靠回调一次减一秒，这种写法在息屏或卡顿后很容易漂移。正确做法是在开始时用单调时钟算出截止时间，亮屏时拿当前时间重算剩余量；用户按暂停时记下剩余量，继续时再算一个新的截止时间。页面刷新可以随页面停掉，到期处理交给自己的定时器。

如果你要在屏幕关闭期间提醒，建议先检查 `time` 服务组是否达到版本 2，再看 `timer_set_background` 是否成功。后台回调可以改计时状态或发通知，但息屏时别碰 LVGL 控件。支持后台定时器的固件也可能让 CPU 休眠，需要持续运行时才持有唤醒锁，任务结束就释放，别一直攥着。如果目标固件不支持后台定时，就只能等亮屏后补处理到期事件，没法保证息屏时准点。[时钟与定时器服务](https://github.com/AstralSightStudios/Canopus/blob/main/docs/canopus-services-specification.md)

## 模块停止与重启

`deactivate` 负责停止后台任务、取消订阅，`stop` 再释放模块还持有的句柄和内存。用户确认修改设置时就保存，不要攒到退出时再写，断电前未必有机会走清理回调。单调时钟的截止值也只在本次开机有效，要跨重启恢复，得另外保存状态，并确认目标能提供真实时钟。

真机上多进出几次页面，留意旧回调还在不在、刷新定时器有没有多建。息屏到期和停用后重启也要分别试：前者看任务能不能继续，后者看模块停用后还会不会触发。
