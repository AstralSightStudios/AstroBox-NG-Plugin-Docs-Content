---
title: "关于Linoval Sans"
description: "了解 Aeris UI Gallery 为手环窄屏设计的 Linoval Sans 字体。"
---

Aeris UI Gallery 用的是 Linoval Sans。这套字体基于 Inter 4.2 的直立体，针对手环窄屏上的英文标签、日期和计时数字重新调整了字形。首版覆盖基本 ASCII，另外补了度号、中点和数学减号这些常用符号，所以 `Wed 09/30` 和 `−12 °C` 这类读数能正常排出来。

窄屏上最麻烦的是宽度。Linoval Sans 会按字形结构分别调整，而不是把整套字压窄。拿 `o` 和 `0` 来说：`o` 在上下圆弧之间加了一小段直边，`0` 只轻微收窄，保留数字本身的轮廓。字重越粗，收窄幅度反而越小，否则字腔里的留白会被挤没。

字体还按阅读场景分了光学尺寸。小字号标签用 Text 光学尺寸，计时卡上的大号数字用更大的光学尺寸，笔画端头也更圆。圆润度可以独立于字重和光学尺寸调整；切换时字宽和字偶间距保持不变，同一行文字不用重新排版。这个约束挺重要，不然动画一动，整行字就会跟着抖。

计时卡使用等宽数字。数字变化时，各位的位置和整串读数的宽度都保持稳定；冒号的两个点对齐到数字高度的中线，默认的平顶 `3` 也保留了圆顶替代字形。Aeris 会把选定的字形导出成静态字体和设备字形资源，计时卡用的等宽数字与居中冒号在导出时直接写进字符映射。实际切换效果可以在[滚动数字](./rolling-time.mdx)里看。
