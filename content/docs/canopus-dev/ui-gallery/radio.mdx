## Rust 用法

```rust title="Rust"
use aeris_ui::device::{cards::Choice, lv};

let card = unsafe { lv::card(root, 4, 108) };
let mut radio = unsafe { Choice::radio(card, "Reminder", "Tap to select", false) };
lv::bind(card, on_select, 0);

// 应用确认选择后更新标记。
radio.set_selected(true);
```

## 接口用法

| 参数或事件 | 说明 |
| --- | --- |
| `card` | 承载单选标记的卡片对象。 |
| `title, subtitle` | 两行卡片文字。 |
| `selected` | 初始选中状态。 |
| 回调与事件 | 点击事件由卡片接收。组件通过 set_selected 或 animate_to 反映应用状态。 |

## 适用条件

一个选项配一个圆形标记时用它。要管理多个互斥选项，别拿一堆 `radio` 自己维护状态，直接用 `ChoiceList` 更省事，选中同步也是现成的。

设备端入口：`device::cards::Choice::radio`
