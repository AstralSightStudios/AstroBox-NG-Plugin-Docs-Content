## 当前实现边界

- 用户只导入一张图片。
- `layers` 是唯一的新格式图层结构来源，按数组从底到顶渲染。
- 用户不能新增、删除、复制或重排图层。
- 所有 `wallpaper` 图层引用同一张用户图片并共享同一套位移、缩放和旋转。
- 文字图层通过 Typr.js 解析可变字体并在 Canvas 上绘制 outline，与平台无关。
- 玻璃图层为软件实现的 Liquid Glass（Apple profile），支持几何、材质与打光参数。
- 预览、PNG 导出和应用到表盘共用同一个 Canvas 渲染器。
- 仅已安装且记录了壁纸配置关联的表盘会出现可用入口。
- 新格式当前只接受 `version: 1`。
