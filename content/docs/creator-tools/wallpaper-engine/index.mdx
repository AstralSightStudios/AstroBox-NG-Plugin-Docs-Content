## 是什么

壁纸生成器允许用户导入**一张图片**，结合开发者用 JSON 定义的图层结构，在设备上调整有限参数并导出 PNG 应用到表盘。

- 创作者通过 JSON 定义画布、设备模板、图层、素材与可调参数；
- 用户导入一张图片，进行缩放 / 旋转 / 平移，调整 JSON 开放的参数，导出或应用。

## 五种图层

| 类型 | 数据来源 | 用途 |
| --- | --- | --- |
| `wallpaper` | 用户导入的唯一图片 | 背景、模糊底图、局部清晰副本 |
| `asset` | 开发者提供的固定素材 | 玻璃、边框、装饰、可换色素材 |
| `tint` | 纯色填充 | 变亮、变暗或颜色覆盖 |
| `text` | 开发者字体 + 用户可编辑文本 | 表盘文字、时间、日期 |
| `glass` | 程序化生成 | 液态玻璃、磨砂、折射与高光 |

## 核心概念

- **单一图片源**：所有 `wallpaper` 图层共用同一张用户图片和同一套取景（位移、缩放、旋转）。
- **JSON 是结构来源**：图层数量、类型、顺序和参数均由 JSON 决定。
- **有限可调**：只有 JSON 中显式开放（`adjustable`）的参数会在界面上显示控件。

## 快速开始

1. 安装并登录 [CreatorConsole](/docs/creator-tools/index)。
2. 在资源发布流程中选择壁纸，使用可视化编辑器搭建图层。
3. 导出配置后托管 JSON 与素材，并在资源 manifest 中声明配置地址。

完整流程见[创建与发布流程](./getting-started)，JSON 结构见[配置参考](./config-reference)。
