title: 概念
description: 在开始账号配置前，先了解 CreatorConsole 中的账号概念。
---

在 CreatorConsole 中，你一共需要登录两个账号才能解锁所有的功能，其分别是 Github 账号与 AstroBox 账号。

## Github 账号

Github 账号主要用于资源的上传与提交。在登录账号后，CreatorConsole 会使用你的 Github 账号帮助你提交资源 PR，并在资源提交被同意并合并后自动更新到 AstroBox 平台。

如果你想要了解如何在 CreatorConsole 中登录 Github 账号，可以点击查看[这篇文档](./account/gh)。

## AstroBox 账号

AstroBox 账号主要用于使用 CreatorConsole 中的特色功能。包括但不限于资源数据的查看、分析，以及使用 CreatorPlus 和 CreatorPro 等高级功能。

如果你想要了解如何在 CreatorConsole 中登录 AstroBox 账号，可以点击查看[这篇文档](./account/ab)。
