---
title: 资源内容规范
description: AstroBox 官方社区源的资源内容、质量、版本与版权要求
---

提交至 AstroBox 官方社区源的资源，必须满足以下内容、质量、版本与版权要求。存在问题时，审核员会在 Pull Request 中公开提出修改意见；完成修改并通过审核后，资源才会合并发布。

## 内容与质量

1. 资源不得包含色情低俗、不良导向、政治敏感内容，以及其他违反[中华人民共和国法律](https://flk.npc.gov.cn/index)或用户所在地法律法规的内容。
2. 资源必须具备基本完整度、原创性与实际使用价值。仅替换模板图片的表盘、功能过于简陋的快应用等低质量资源可能无法通过审核。
3. 资源不得包含明显影响使用的故障，包括无法安装、无法启动、核心功能失效、严重显示异常或频繁崩溃。
4. 资源必须能在其声明支持的设备上正常运行基本功能；未经验证的设备不得标记为支持。
5. 资源的名称、描述、预览图与实际内容必须一致，不得夸大功能或误导用户。
6. 试用版、包含应用内购买的资源必须明确标注付费属性，不得隐瞒功能限制或收费内容。
7. 付费资源应提供与售价相符的完成度、稳定性和使用价值。

## 版本要求

1. 每次发布必须提供明确、可辨识的资源版本号，并在 `downloads.version` 中如实填写。
2. 更新资源时必须递增版本号，不得以相同或更低的版本号覆盖已有版本。
3. 同一版本号必须对应同一份资源内容；资源文件发生变化时应同步更新版本号。
4. 同一构建适配多个设备时应使用一致的版本号；不同设备版本存在功能或内容差异时，应分别准确标注。
5. 不得通过无实际内容的版本更新反复刷新资源。
6. 版本更新不得降低资源的基本可用性；存在已知限制时，应在资源描述或更新说明中明确告知。

## 版权要求

1. 禁止未经原作者授权搬运、转载或盗传他人资源。
2. 禁止明显剽窃他人创意。存在争议时，审核员会在 Pull Request 中讨论并要求补充说明。
3. 使用知名 IP 素材时，必须在 `preview` 中加入版权声明图，明确该素材及 IP 与 AstroBox、小米无关。

## 展示素材

1. `cover` 应清晰、美观，避免低质、简陋或无法体现资源内容的设计。
2. `cover` 比例应为 `3:2`，推荐尺寸为 `1200 x 800`。
3. `icon` 推荐尺寸为 `192 x 192`，暂无硬性尺寸要求。
