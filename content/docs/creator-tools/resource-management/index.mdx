在 CreatorConsole 中，「资源管理」系列功能是你完成资源上架、更新与售卖的核心工作台，也是你洞察用户数据、优化作品的看板。无论是免费的表盘、快应用，还是需要接入外部平台的付费资源，都可以通过这里统一提交并追踪审核状态。

## 你可以做什么

- **发布新资源**：填写资源基础信息、上传媒体素材与包体，一键创建 GitHub 仓库并向官方仓库提交 Pull Request。
- **管理已上传资源**：在「资源管理」页面查看你名下所有资源的审核状态、版本记录与线上表现。
- **接入付费平台**：绑定爱发电等第三方平台，配置商品映射与 Webhook，实现付费校验与自动激活。
- **启用资源加密**：为付费资源开启加密上传，保护你的创作成果不被随意分发。

## 开始之前

在进入具体流程前，请确保你已经完成以下准备：

- 熟悉 CreatorConsole 中的 [账号概念](../account) 并完成 GitHub 与 AstroBox 账号的登录。
- 了解 AstroBox 的 [资源规范](../resource-std/content)，避免因不符合规范导致审核未通过。
- 如需发布付费资源，请提前订阅 CreatorPlus 或更高档位会员，并注册好 [爱发电](https://ifdian.net/) 账号。
