## 打开管理器
在通过表盘激活 Canopus 管理器后，进入应用启动器，即可看到“Canopus 管理器”应用。

## 首页
在管理器首页，将显示管理器版本、固件版本等信息：

  <img src="/assets/images/docs/usage/canopus/20260818222455_6.png" style={{ width: '30%', borderRadius: '30px' }} />
  <img src="/assets/images/docs/usage/canopus/20260818222552_7.png" style={{ width: '30%', borderRadius: '30px' }} />
</div>

## 模块页
在首页中点击“模块”按钮即可进入模块列表，在模块列表中点击对应模块即可进入其详情页：
<div style={{ display: 'flex', gap: '10px' }}>
  <img src="/assets/images/docs/usage/canopus/20260818222625_8.png" style={{ width: '30%', borderRadius: '30px' }} />
  <img src="/assets/images/docs/usage/canopus/20260818222702_9.png" style={{ width: '30%', borderRadius: '30px' }} />
</div>

下滑即可进行“更新”“禁用”“移除”等操作，所有操作都将在重启后生效（别忘了重新激活管理器）：
