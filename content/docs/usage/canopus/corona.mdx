## 安装

前往“资源”页，搜索“Corona”即可进行安装。安装模块将捆绑安装快应用管理器

模块的具体安装与启用流程，请参照[通用教程](/docs/usage/canopus/install)

## 使用

### 资源导入

`资源包`在 AstroBox 中已经成为一种资源类型，你可以在资源市场搜索并下载

### 资源应用

在导入资源包之后，点击管理器首页最底下的重载按钮就可以应用你的资源包

### 资源管理

点击首页的`资源管理`可以进入资源管理页

在资源管理页中可以看到已安装的资源包

长按资源包可以对资源包进行排序，资源包的顺序将影响内容的优先级（类似我的世界）

- 上方的资源会**覆盖**下方的资源
- 系统资源下方的资源将不会被应用

点击资源包可以查看资源包的详细信息，**双击**资源包详细信息的删除按钮可以删除资源包

删除资源包时会检查资源包有没有被**加载**，“加载”包括：

- 排在系统资源上方的资源
- 在`混搭微调`中被选中的资源

如果资源包被加载，删除操作将被阻止。
想要取消加载，请调整相关配置并**重载**。

所有的配置都会**实时保存**。

### 混搭微调

点击首页的混搭微调将会进入混搭微调界面，这里你可以看到每一个被资源包替换的资源

你可以针对某一个资源改成你想要的版本，无论你在资源页是怎么排序的。

点击混搭微调界面的资源可以进入资源选择页面，在这里，你可以看到

- 默认（不进行微调）
- 系统（系统内置资源）
- 和你所有安装的资源包

你可以点击资源选择页面的资源来选择你想要的版本，对于图片资源，你还可以看到对应的预览图

所有的配置都会**实时保存**。

### 加载配置

点击首页的重载，管理器将会把你的配置发给模块，模块会根据你的配置来加载资源。
完成重载后，你的配置将会被应用，资源包将被加载。

## 资源包制作

### 1. 手工制作

在AstroBox的插件商城搜索`corona`安装"Corona CRPack Builder"，

进入插件后先导入一个实机固件，固件可以在[AstroBox固件库](https://github.com/AstralSightStudios/MiWearFirmwareArchives/releases)下载。

导入后，可以在左边看到固件内的文件树，你可以浏览固件内的文件并进行替换操作。

替换完成后，点击导出crpack，即可保存你的资源包。

编辑器最下方还可以更换第三方应用的资源包

### 2. AI cli操作

你可以安装corona-cli来让ai辅助图标包制作

```bash
cargo install --locked corona-cli
```

安装之后，可以命令ai帮忙查看某个固件差什么图标，然后进行替换操作。

也可以自己适配了一个固件之后让帮你适配更多固件

### 3.注意事项

资源包上传到AstroBox社区源时，请注意id和themeid相同，记得填写作者和versionCode，以便用户检查更新。

我们不反对ai生成，但是资源必须要精心制作
