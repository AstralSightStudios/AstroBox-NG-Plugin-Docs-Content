## 支持情况
目前支持的设备/固件版本如下：
|设备型号|支持的固件版本|备注|
|-|-|-|
|小米手环10 Pro (中国大陆版)|`3.101.036`||

## 安装管理器
打开 AstroBox，**连接设备**，进入**资源**页面，搜索`Canopus模块管理器`即可安装：
![](/assets/images/docs/usage/canopus/install_manager.png)

安装完后，可以看到设备上多了一个表盘，点击“Run”按钮即可激活管理器。

管理器激活成功后，将发出通知：

<img src="/assets/images/docs/usage/canopus/20260818224333_14.png" style={{ width: '30%', borderRadius: '30px' }} />

## 安装模块
在安装模块前，请先确保你已激活最新版本的 Canopus 模块管理器。

AstroBox 官方社区源提供 Canopus 模块的安装。进入**资源页面**，将资源类型过滤设置为**模块**即可看到社区源中提供的模块：
![](/assets/images/docs/usage/canopus/module_filter.png)

安装前，请先确保目标模块支持你的设备，且你的设备正在运行受支持的固件版本。

模块将以表盘的形式被安装到设备，随后调用 Canopus 管理器预留的接口释放资源并安装。在模块安装完成后，管理器将发出通知：

<img src="/assets/images/docs/usage/canopus/20260818224548_15.png" style={{ width: '30%', borderRadius: '30px' }} />

此时打开 Canopus 管理器，下滑，进入“模块”页，点击你刚刚安装的模块，下滑点击“启用”，并确认启用即可：

<img src="/assets/images/docs/usage/canopus/20260818224618_16.png" style={{ width: '30%', borderRadius: '30px' }} />

确认启用后，重启设备，切换到管理器激活表盘，再次点击“Run”以激活 Canopus 模块管理器，已启用的模块也将一同生效。
