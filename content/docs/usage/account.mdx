## 概念

AstroBox 账号是我们全新推出的账号体系。它可以绑定 Github 账号、米坛账号、爱发电账号，以达成从「社区互动」到「付费资源激活」到「创作者资源绑定」的全体系账号服务。

## 账号注册与登录

在设置中点击上方账号设置的「更多设置」，然后在账号页面中点击上方的「登录按钮」，即可开始 AstroBox 账号的登录与注册。

![](/assets/images/docs/usage/account/3.png)

进入这个页面后，你可以直接凭借米坛账户登录，系统会一并为你注册好 AstroBox 账号并完成米坛账号与 AstroBox 账号的绑定。

如果提示「OUs2:"invalid_request"」相关字样，请给米坛设置一个头像再重新尝试～（请不要在无账号注册的情况下直接使用 GitHub 和爱发电账号登录）

如果提示需要邀请码、邀请码不能为空的，请尝试在 [https://ascas.waterflames.cn/login/astrobox](https://ascas.waterflames.cn/login/astrobox) 注册登录一下，再回到 AstroBox 重新唤起登录账号。

![](/assets/images/docs/usage/account/2.png)

你也可以点击注册按钮进入网页，手动填写信息，通过邮箱来注册并登录 AstroBox 账号。

注册过程中如果邮箱没提示收到邮件，可以尝试在垃圾邮件里寻找一下。

如果提示需要邀请码、邀请码不能为空的，请尝试在 [https://ascas.waterflames.cn/login/astrobox](https://ascas.waterflames.cn/login/astrobox) 注册登录一下，再回到 AstroBox 重新唤起登录账号。

## 账号绑定

登录 AstroBox 账号后，需绑定其它平台账户的，请到 AstroBox 账号管理中添加。你也可以在设置中点击上方账号设置的「更多设置」，在账号页面中部有各个平台的「绑定按钮」，其中 Github、爱发电、米坛是绑定后有实际作用的平台，你可以逐一点击右侧完成绑定。爱发电平台因为特殊原因只允许国内 IP 完成绑定登录，请你在登录前确认。若你无法绑定米坛账号，提示「OUs2:"invalid_request"」相关字样，请给米坛设置一个头像再重新尝试～

![](/assets/images/docs/usage/account/4.png)

## 权益与资源激活

AstroBox 理论支持其他平台接入作为资源付费激活验证，但在这里我们以第一方支持良好的爱发电平台举例。

进行权益与资源激活前，请你保证：你购买权益或资源所使用的爱发电账号已绑定到你当前使用的 AstroBox 账号上。

接下来，你需要先使用你的爱发电账号进行权益或资源的购买。如果你购买的是资源，那么购买的链接一般会在资源页找到；如果是权益，在权益页面也有可以跳转的链接。购买过程中不需要登记任何内容，购买记录会同步在你的爱发电账号中。我们推荐这个过程在爱发电账号与 AstroBox 账号绑定后进行，否则订单记录可能会出现丢失的情况。

在购买完成之后，进入 AstroBox，相关权益会即时生效，购买的资源会为你开放下载安装权限。如果这个过程没有及时发生，请你退出登录并重新登录一遍 AstroBox 账号，随后便会刷新当前的平台授权与权益的更新。
