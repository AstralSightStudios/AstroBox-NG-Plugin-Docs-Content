---

## 常见报错与解决方案

### device.connect.noDevice（无已连接设备）

<a id="music-no-device" />

**报错原文**

```text
device.connect.noDevice
```

**触发场景**：音乐导入/上传开始时没有已连接的设备，任务卡片也会显示此错误。

**解决方案**：先连接设备再导入音乐。

**源码位置**：`logic/queue/musichelper.ts:120`

### Music file is empty

<a id="music-file-empty" />

**报错原文**

```text
Music file is empty
```

**触发场景**：上传的音乐文件内容为空（0 字节或读取失败）。

**解决方案**：确认音乐文件未损坏且大小正常，重新选择文件。

**源码位置**：`frontapi/device/music.rs:271`

### Songlist operation failed（歌单操作失败）

<a id="songlist-op-failed" />

**报错原文**

```text
Songlist operation failed: {code:?}
```

**触发场景**：设备端歌单操作（添加/移除歌曲等）返回失败状态码。

**解决方案**：检查设备连接状态，或稍后重试；如反复失败重启设备。

**源码位置**：`frontapi/device/music.rs:309` / `frontapi/device/music.rs:453`

### Device rejected the song removal request

<a id="song-removal-rejected" />

**报错原文**

```text
Device rejected the song removal request
```

**触发场景**：设备拒绝了歌曲移除请求（常见于存储异常或设备忙）。

**解决方案**：检查设备存储空间，或重启设备后重试。

**源码位置**：`frontapi/device/music.rs:252`

### device.music.songlistLimitReached（歌单数量达上限）

<a id="songlist-limit" />

**报错原文**

```text
device.music.songlistLimitReached
```

**触发场景**：创建歌单时数量已达到设备上限。

**解决方案**：删除不必要的歌单后再创建。

**源码位置**：`pages/device/music.tsx:297`

### 五、其他排查建议

| 报错 | 建议操作 |
|------|----------|
| `device.music.songlistNameRequired` | 确保输入了歌单名称 |
| `device.music.selectSongsRequired` | 至少选择一首歌曲 |
| `Music file data is missing` | 确认文件已成功选择，重新选择文件 |
