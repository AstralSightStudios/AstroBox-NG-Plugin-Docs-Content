| `frontapi/app.rs:209` | `failed to probe dev server after spawn` | 开发服务器启动后探测失败 |

### 热更新

## 五、常见排查建议

| 报错 | 建议操作 |
|------|----------|
| `account.sessionExpired` | 重新登录 AstroBox 账号 |
| `update.toast.checkFailed` | 检查网络连接，或稍后重试 |
| `settings.sponsorPlan.trialLoginRequired` | 先登录 AstroBox 账号 |
| `settings.sponsorPlan.iapPurchaseFailed` | 检查 App Store 账户状态，或稍后重试 |
| `settings.sponsorPlan.iapVerifyPendingRetry` | 等待验证完成，不要关闭应用 |
| `frontend invoke ... dropped without response` | 检查应用是否被系统挂起，重启应用 |
| `NTP query failed` | 检查网络连接，或手动设置时间 |
| `Failed to load device version snapshots` | 检查存储权限，或重启应用 |
| `Invalid version response format` | 更新服务器可能临时异常，稍后重试 |
| `app is not ready` | 等待应用完全启动后再操作 |
