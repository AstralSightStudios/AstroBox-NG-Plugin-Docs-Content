## 常见报错与解决方案

### settings.general.runtimeCache.failed（运行时缓存清理失败）

<a id="cache-clear-failed" />

**报错原文**

```text
settings.general.runtimeCache.failed + <错误消息>
```

**触发场景**：清理运行时缓存失败（`failed to clear cache: {failures}`，常见于文件被占用或权限不足）。

**解决方案**：检查存储权限，关闭可能占用缓存文件的窗口，或手动清理缓存目录。

**源码位置**：`pages/settings/general.tsx:288`（前端）；`frontapi/app.rs:334`（后端）

### settings.network.doh.invalidCustomUrl（自定义 DOH 地址无效）

<a id="doh-invalid-url" />

**报错原文**

```text
settings.network.doh.invalidCustomUrl
```

**触发场景**：自定义 DOH URL 为空或格式无效，或 DOH 配置写入失败。

**解决方案**：确认 DOH URL 格式正确，以 `https://` 开头。

**源码位置**：`pages/settings/networkShared.tsx:522/549/577/590`；逻辑层 `logic/networkSettings.ts:186`（`invalid-custom-doh-url`）

### settings.network.speedTest.failed（测速失败）

<a id="speed-test-failed" />

**报错原文**

```text
settings.network.speedTest.failed
```

**触发场景**：所有测速探针均超时或失败。

**解决方案**：检查网络连接，或切换其他网络后重试。

**源码位置**：`pages/settings/networkShared.tsx:638`

### settings.extratools.fetchLogs 失败（获取设备日志失败）

<a id="fetch-logs-failed" />

**报错原文**

```text
error.message / String(error)
```

**触发场景**：获取设备日志失败（常见触发链：`failed to decode reverse MASS packet` / `failed to assemble reverse MASS payload: block N was not found!`，设备侧丢包）。

**解决方案**：检查设备连接状态；如为 MASS 丢包，拉取前先重启设备、清理手表内存。

**源码位置**：`pages/settings/extratools.tsx:1099`；设备侧 `modules/core/src/device/xiaomi/components/mass.rs:251`、`packet/mass.rs:215`

### settings.extratools.transportDiag 相关失败（传输诊断失败）

<a id="transport-diag-failed" />

**报错原文**

```text
message（归一化错误）
```

**触发场景**：传输抓包开始/停止、冒烟测试失败（常见于设备断联或蓝牙异常）。

**解决方案**：确认设备已连接，检查蓝牙状态后重试。

**源码位置**：`pages/settings/extratools.tsx:948/975/1010`；后端 `frontapi/device/transport_diag.rs`

### filePicker.openFailed（文件选择器打开失败）

<a id="file-picker-failed" />

**报错原文**

```text
filePicker.openFailed / filePicker.openFailed: <detail>
```

**触发场景**：Tauri 或 Web 文件选择器调用异常，或移动端选择了不支持的操作（如移动端文件夹选择）。

**解决方案**：确认系统文件选择权限；移动端不支持文件夹选择，改用文件选择。

**源码位置**：`logic/filePicker.ts:144`；后端 `frontapi/file_picker.rs:152/453`

### 分享相关失败（sharing is not supported 等）

<a id="share-failed" />

**报错原文**

```text
sharing is not supported on this platform / 当前系统不支持原生文件分享 / 拉起系统分享超时
```

**触发场景**：当前平台不支持系统分享，或分享超时/失败。

**解决方案**：当前平台不支持系统分享功能；如为超时可稍后重试。

**源码位置**：`frontapi/app.rs:543/727/740/769/779`

### No recordings selected（未选择录音）

<a id="no-recordings-selected" />

**报错原文**

```text
No recordings selected
```

**触发场景**：导出录音时未选择任何录音。

**解决方案**：先选择要导出的录音。

**源码位置**：`frontapi/device/record.rs:161`

### Recording `{name}` cannot be exported（录音格式不支持导出）

<a id="record-export-unsupported" />

**报错原文**

```text
Recording {name} cannot be exported
```

**触发场景**：录音格式不支持导出。

**解决方案**：该录音格式不支持导出，尝试其他方式。

**源码位置**：`frontapi/device/record.rs:511`

### Failed to open debugwindow（调试窗口打开失败）

<a id="debug-window-failed" />

**报错原文**

```text
Failed to open debugwindow：<message>
```

**触发场景**：打开调试窗口失败（注意：这是项目中唯一一处使用原生 `alert()` 展示的报错，非 toast）。

**解决方案**：检查窗口管理器权限，或重启应用。

**源码位置**：`pages/settings/extratools.tsx:644`

### 四、其他排查建议

| 报错 | 建议操作 |
|------|----------|
| `device.noDevice` | 先连接设备再执行相关操作 |
| `settings.network.speedTest.noAvailableResult` | 检查网络连接，或切换其他网络后重试 |
| `settings.notifications.remotePush.permissionDenied` | 在系统设置中开启推送权限 |
| `settings.extratools.watchfacePreview.nativeOnly` | 表盘预览仅支持 Tauri 桌面端 |
| `clipboard unavailable` | 检查浏览器/系统剪贴板权限 |
