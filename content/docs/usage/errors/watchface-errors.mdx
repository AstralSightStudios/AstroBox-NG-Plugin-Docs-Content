## 三、队列内嵌报错（progressDesc）

表盘安装任务若失败，`taskList.ts` 会将错误写入 `progressDesc`：

- `queue.watchfaceIdConflict` — 表盘 ID 冲突/降级冲突
- `resource.unknown.type` — 文件类型未知
- `device.connect.noDevice` — 安装时无设备连接

## 五、常见排查建议

| 报错 | 建议操作 |
|------|----------|
| `device.watchfaces.edit.text.invalid` | 检查文本内容是否符合表盘规范 |
| `device.watchfaces.edit.text.fontMissing` | 确保只选择了一种字体，或选择有效字体 |
| `device.watchfaces.edit.text.fontReadFailed` | 确认字体文件未损坏，尝试更换字体文件 |
| `device.watchfaces.edit.applyFailed` | 检查设备连接状态，确认表盘文件完整 |
| `queue.watchfaceIdConflict` | 确认是否覆盖安装，或更换不同 ID 的表盘 |
| `hb_subset_or_fail failed` | 字体文件可能不兼容，尝试使用标准 TTF/OTF 字体 |
| `subset produced empty font` | 确认文本内容不为空，且字体支持对应字符 |
