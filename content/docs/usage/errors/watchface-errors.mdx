## 常见报错与解决方案

### queue.watchfaceIdConflict（表盘 ID 冲突）

<a id="watchface-id-conflict" />

**报错原文**

```text
queue.watchfaceIdConflict
```

**触发场景**：安装表盘时检测到 downgrade 冲突（设备上已有同 ID 或更高版本的表盘）。toast 会附带「覆盖安装」按钮，也可在设置中开启「强制安装表盘」。

**解决方案**：确认是否覆盖安装，或更换不同 ID 的表盘。

**源码位置**：`logic/queue/installhelper.ts:169`（前端）；设备端对应 `install prepare failed with status: Downgrade`（`modules/core/src/device/xiaomi/components/install.rs:207`）

### device.watchfaces.edit.text.invalid（文本验证失败）

<a id="watchface-text-invalid" />

**报错原文**

```text
device.watchfaces.edit.text.invalid
```

**触发场景**：应用表盘编辑时自定义文本内容不符合表盘规范。

**解决方案**：检查文本内容是否符合表盘规范（长度、字符集等）。

**源码位置**：`pages/device/watchfaceEdit.tsx:1071`

### device.watchfaces.edit.text.fontMissing（字体缺失/多选）

<a id="watchface-font-missing" />

**报错原文**

```text
device.watchfaces.edit.text.fontMissing
```

**触发场景**：文本字面量未选择字体，或同时选择了多种字体。

**解决方案**：确保只选择了一种字体，或选择有效字体。

**源码位置**：`pages/device/watchfaceEdit.tsx:1113`

### device.watchfaces.edit.text.fontReadFailed（字体读取失败）

<a id="watchface-font-read-failed" />

**报错原文**

```text
device.watchfaces.edit.text.fontReadFailed
```

**触发场景**：读取本地字体文件失败（文件损坏或权限问题）。

**解决方案**：确认字体文件未损坏，尝试更换字体文件。

**源码位置**：`pages/device/watchfaceEdit.tsx:1230`

### device.watchfaces.edit.applyFailed（表盘应用失败）

<a id="watchface-apply-failed" />

**报错原文**

```text
device.watchfaces.edit.applyFailed
```

**触发场景**：表盘编辑应用（推送）失败，常见于设备断联或表盘文件不完整。

**解决方案**：检查设备连接状态，确认表盘文件完整后重试。

**源码位置**：`pages/device/watchfaceEdit.tsx:1147`

### hb_subset_or_fail failed（字体子集化失败）

<a id="font-subset-failed" />

**报错原文**

```text
hb_subset_or_fail failed (font unsupported?)
```

**触发场景**：HarfBuzz 对所选字体做子集化失败，字体格式不受支持。

**解决方案**：字体文件可能不兼容，尝试使用标准 TTF/OTF 字体。

**源码位置**：`logic/fontSubset.ts:92`

### 三、队列内嵌报错（progressDesc）

表盘安装任务若失败，`taskList.ts` 会将错误写入 `progressDesc`：

- `queue.watchfaceIdConflict` — 表盘 ID 冲突/降级冲突
- `resource.unknown.type` — 文件类型未知
- `device.connect.noDevice` — 安装时无设备连接
