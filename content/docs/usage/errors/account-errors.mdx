本文档汇总 AstroBox 在小米/vivo 账号登录、AstroBox 账号管理、绑定解绑等流程中可能向用户展示的报错信息。**常见报错与解决方案已置顶**，完整清单见文末。

---

## 常见报错与解决方案

### 登入失敗：serviceLoginAuth2 returned credential challenge again

<a id="login-credential-challenge" />

**报错原文**

```text
登入失敗：serviceLoginAuth2 returned credential challenge again; body=xxxxxxxxx
```

**触发场景**：小米账号登录第二步认证（serviceLoginAuth2）时仍返回凭据校验要求，即登录时账号或密码错误。

**解决方案**：确认账号密码正确，注意大小写；如忘记密码请先通过小米官方渠道找回。

**源码位置**：`src-tauri/modules/account/src/xiaomi.rs:1593`

### 小米账号登录失败：用户名或密码错误

<a id="xiaomi-wrong-credentials" />

**报错原文**

```text
小米账号登录失败：用户名或密码错误
```

**触发场景**：小米账号用户名或密码错误（API 返回 70016 时同样显示「登录失败：用户名或密码错误」）。

**解决方案**：确认账号密码正确，注意大小写，或通过小米官方渠道找回密码。

**源码位置**：`frontapi/account.rs:1746` / `frontapi/account.rs:2094`

### 原生小米账号登录窗口已在运行，请关闭后重试

<a id="xiaomi-login-window-conflict" />

**报错原文**

```text
原生小米账号登录窗口已在运行，请关闭后重试
```

**触发场景**：登录窗口已打开时再次触发登录。

**解决方案**：关闭已有的登录窗口后重试。

**源码位置**：`frontapi/account.rs:270`

### 等待小米账号两步验证超时

<a id="xiaomi-2fa-timeout" />

**报错原文**

```text
等待小米账号两步验证超时
```

**触发场景**：两步验证（2FA）页面未在预期时间内完成验证。

**解决方案**：检查网络连接，确认验证码/二次验证操作已完成，或尝试重新登录。

**源码位置**：`frontapi/account.rs:605` / `frontapi/account.rs:824`

### vivo 登录已完成，但未能从页面或 cookie 中取得 openid

<a id="vivo-missing-openid" />

**报错原文**

```text
vivo 登录已完成，但未能从页面或 cookie 中取得 openid
```

**触发场景**：vivo 登录流程走完但拿不到 openid，常见于网络异常或页面未正常跳转。

**解决方案**：检查网络连接，或尝试重新登录。

**源码位置**：`frontapi/account.rs:939`

### 四、其他排查建议

| 报错 | 建议操作 |
|------|----------|
| `用户名或密码错误` | 确认账号密码正确，注意大小写 |
| `小米账号登录窗口已在运行` | 关闭已有的登录窗口后重试 |
| `等待两步验证超时` | 检查网络连接，或尝试重新登录 |
| `原生验证页未返回 cookie` | 完成 2FA 后确保页面正常跳转，或尝试重新登录 |
| `settings.account.bandBbsSyncNetworkError` | 检查网络连接，稍后自动重试 |
| `账号已被封禁` | 联系 AstroBox 客服了解封禁原因 |
| `你的社交功能已被限制` | 等待限制解除时间到期 |
| `account.sessionExpired` | 重新登录 AstroBox 账号 |
| `Current firmware version is required` | 先连接设备以获取当前固件版本 |
