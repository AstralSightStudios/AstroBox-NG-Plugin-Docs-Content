## 常见报错与解决方案

### plugin.install.unsupported（插件安装不受支持）

<a id="plugin-install-unsupported" />

**报错原文**

```text
plugin.install.unsupported
```

**触发场景**：在非 Tauri 环境（Web/WASM）尝试安装插件，或 ABP 文件以 Web File 对象传入。

**解决方案**：插件安装仅支持 Tauri 桌面端，Web/WASM 不支持。

**源码位置**：`logic/queue/installhelper.ts:555` / `logic/queue/pluginhelper.ts:67`

### plugin.install.failed: store base empty（插件存储为空）

<a id="plugin-store-base-empty" />

**报错原文**

```text
plugin.install.failed: store base empty
```

**触发场景**：插件存储基础目录为空，无法写入插件。

**解决方案**：检查插件存储目录权限，或重启 AstroBox。

**源码位置**：`frontapi/plugsys.rs:284`

### Plugin '`{name}`' is disabled（插件已禁用）

<a id="plugin-disabled" />

**报错原文**

```text
Plugin '{name}' is disabled
```

**触发场景**：尝试启动已禁用的插件，或打开已禁用插件的 UI。

**解决方案**：先启用插件再执行操作。

**源码位置**：`frontapi/plugsys.rs:566` / `frontapi/plugsys.rs:602`

### Plugin '`{name}`' is not loaded（插件未加载）

<a id="plugin-not-loaded" />

**报错原文**

```text
Plugin '{name}' is not loaded
```

**触发场景**：插件未正确加载（安装不完整或启动失败）。

**解决方案**：检查插件是否正确安装，尝试重新安装。

**源码位置**：`frontapi/plugsys.rs:577` / `frontapi/plugsys.rs:613`

### Plugin '`{name}`' is not ready（插件未就绪）

<a id="plugin-not-ready" />

**报错原文**

```text
Plugin '{name}' is not ready
```

**触发场景**：插件初始化未完成即被调用 RPC 或查询状态。

**解决方案**：等待插件初始化完成，或重启应用。

**源码位置**：`frontapi/plugsys.rs:644` / `frontapi/plugsys.rs:673`

### aggregate index.json does not contain valid plugins（插件市场索引无效）

<a id="plugin-market-index-invalid" />

**报错原文**

```text
aggregate index.json does not contain valid plugins
```

**触发场景**：插件市场聚合索引文件无效，无法列出可用插件。

**解决方案**：插件市场源配置错误，检查源地址。

**源码位置**：`logic/pluginMarket.ts:308`
