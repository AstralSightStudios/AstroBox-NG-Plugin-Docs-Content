本文档汇总 AstroBox 在从官方源、三方源、加密资源下载等流程中可能向用户展示的报错信息。**常见报错与解决方案已置顶**，完整清单见文末。

---

## 常见报错与解决方案

### resource.purchase.invalidSignature（加密资源签名无效）

<a id="invalid-signature" />

**报错原文**

```text
resource.purchase.invalidSignature
```

**触发场景**：请求加密资源信息失败（非 `file_not_found` 时），或解密后校验签名不通过。

**解决方案**：确认已购买该资源，或重新登录账号刷新授权；如仍失败请联系资源作者。

**源码位置**：`logic/queue/downloadhelper.ts:543`（`maybeResolveEncryptedResourceFile`）

### resource_crypto_hash_mismatch（加密资源哈希不匹配）

<a id="hash-mismatch" />

**报错原文**

```text
resource_crypto_hash_mismatch
```

**触发场景**：加密资源解密后哈希校验不通过，资源文件可能在传输中损坏。

**解决方案**：尝试重新下载资源；如反复失败请联系资源作者确认文件完整性。

**源码位置**：`logic/resourceCrypto.ts:43`

### resource.purchase.decryptFailed（资源解密失败）

<a id="decrypt-failed" />

**报错原文**

```text
resource.purchase.decryptFailed
```

**触发场景**：`commprov_resource_file_decrypt` 调用失败，资源无法解密。

**解决方案**：确认网络稳定，或联系资源提供方确认资源状态。

**源码位置**：`logic/queue/downloadhelper.ts:558`

### No downloadable artifact found

<a id="no-downloadable-artifact" />

**报错原文**

```text
No downloadable artifact found
```

**触发场景**：下载 action 执行时找不到可用下载产物（资源已下架或链接失效）。

**解决方案**：检查资源是否已下架或链接失效，联系资源作者确认。

**源码位置**：`logic/queue/downloadhelper.ts:114`

### resource.unknown.type（未知资源类型）

<a id="unknown-type" />

**报错原文**

```text
resource.unknown.type + <资源名>
```

**触发场景**：下载完成后 `device_get_file_type` 返回的类型无法映射，或 `manifest.item.restype` 无法解析。

**解决方案**：确认资源文件类型正确，或联系资源作者确认类型声明。

**源码位置**：`logic/queue/downloadhelper.ts:156` / `logic/queue/downloadhelper.ts:459`

### 五、其他排查建议

| 报错 | 建议操作 |
|------|----------|
| `No downloadable artifact found` | 检查资源是否已下架或链接失效 |
| `Provider not found` | 检查社区源配置，或尝试刷新源列表 |
| `download url is unavailable` | 该资源当前无可用下载链接 |
| `resource too large` | 资源超过大小限制，联系作者或使用其他渠道 |
| `OfficialV2 device map is not ready` | 等待设备映射加载完成，或刷新页面 |
