# 写在开头

欢迎使用 AstroBox！AstroBox 是业界领先的穿戴设备第三方工具箱，你可以使用 AstroBox 快速连接你的穿戴设备，在穿戴设备上安装表盘、快应用、固件，又或是结合 AstroBox 插件系统触发更多玩法。

本文档将详细介绍各项功能及使用方式，你可以通过「点击选择卡片」快速开始 AstroBox 之旅、定位问题、前往你想要了解的地方。
